A Node 22 program that writes one complete story in exactly six words to
`/output/entry.txt`:

> He counted stars. She counted exits.

Two people, one night, a marriage ending — the turn is the repeated verb
with a different object: he counts stars, she counts exits.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
